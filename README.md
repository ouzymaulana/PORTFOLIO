# Ouzy Maulana — Portfolio

Single-page portfolio built with React + Vite.

```bash
npm install
npm run dev      # local dev server
npm run build    # production build into build/
npm run preview  # serve the build
```

Content lives at the top of `src/App.jsx` (roles, projects, stack). To show a real app screenshot for a role, import the image and set its `shot` field.
